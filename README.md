
# 校园失物招领系统
结对项目：校园失物招领 Web 前端项目
> 纯前端实现，使用 localStorage 本地存储，无需后端，Chrome浏览器直接打开html运行

## 目录结构

```

campus-lost-found/
├── index.html        # 首页，浏览失物招领列表、搜索
├── publish.html      # 发布寻物启事 / 招领启事
├── detail.html       # 物品详情页面，查看联系方式，修改状态
├── css/style.css     # 全局样式
├── js/data.js        # 本地存储工具函数
├── js/index.js       # 首页 js 逻辑
├── js/publish.js     # 发布页 js 逻辑
├── js/detail.js      # 详情页 js 逻辑
├── images/           # 图片资源文件夹
└── README.md         # 项目说明

```

## 使用说明
1. 下载全部项目文件
2. 使用谷歌 Chrome 浏览器打开 index.html
3. 功能：发布寻物/招领信息，浏览列表，关键词搜索，查看详情，标记【已找到/已归还】
4. 数据保存在浏览器本地存储，清空浏览器缓存会丢失数据
